# F03: Economía completa y sistema de mejoras
**Objetivo:** infraestructura de contenido y balance que escalará a cientos de mejoras.
**Specs:** REQ-UPG-01..05, REQ-CROP-02..04, REQ-ECO-02..06, REQ-QA-02.

## Tareas
- [ ] T3.1 Modelo de mejoras por datos: categorías, niveles, efectos, requisitos de desbloqueo.
- [ ] T3.2 UI de mejoras: precio, nivel, efecto, beneficio esperado, siguiente coste, requisitos, x1/x10/x25/max.
- [ ] T3.3 Resolución de multiplicadores (aditivo/multiplicativo) con orden definido y tests.
- [ ] T3.4 Sistema de cultivos con los 8 tipos (datos); desbloqueo por requisitos.
- [ ] T3.5 Mantenimiento con salvaguardas anti-negativo.
- [ ] T3.6 Simulador de balance v1: perfiles activo/casual/idle, detección de muros y mejoras dominantes.
- [ ] T3.7 Panel de "siguiente objetivo cercano" (regla: siempre hay algo comprable pronto).
- [ ] T3.8 Ajuste de curva Eras 1–2 con el simulador.

## Definition of Done
Informe de simulación sin muros > umbral en Eras 1–2; toda mejora con test de efecto real.
